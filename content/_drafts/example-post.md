Write in plain paragraphs. A blank line starts a new paragraph.

## Use "##" for a section heading

**Bold** and *italic* work, and so do [links to other pages](/services/individual-counseling/).

### Use "###" for a smaller heading

- A list item starts with a dash
- Numbered lists start with "1."

> A line starting with ">" becomes a pull quote.

Add an image with `![What the image shows](/assets/images/uploads/file-name.jpg)`.

---

Three dashes on their own line draw a divider.
