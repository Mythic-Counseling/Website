# Mythic Counseling of Florida

Static website for Mythic Counseling of Florida, rebuilt from the original Squarespace pages as a Jekyll site published with GitHub Pages.

## Two designs

| Branch | Design |
| --- | --- |
| `main` | **Original design** (this branch): the Squarespace site, rebuilt page for page. `main` is what gets published. |
| `redesign` | **New design**: Services page, single booking button, blog, and browser editing with every word in a `content/` folder. Built on top of `main`. |

Switch with `git switch main` / `git switch redesign` (restart a running local preview afterwards). To publish the redesign, merge it into `main`; see [guide 1](docs/1-put-the-site-on-github.md).

## Structure

| Path | Purpose |
| --- | --- |
| `index.html`, `about/`, `appointments/`, `contact/`, `services/*/` | Pages (page wording is kept verbatim from the Squarespace export) |
| `_layouts/`, `_includes/` | Shared layout, header, footer, SEO head, JSON-LD, image and form components |
| `_data/images.yml` | Image catalogue: dimensions, generated widths, alt text |
| `_data/navigation.yml`, `_data/services.yml` | Menu and service/price data for structured data |
| `assets/css/main.css`, `assets/js/main.js` | Styles (mobile-first) and nav/form behaviour |
| `assets/images/original/` | Master PNGs (not deployed) |
| `assets/images/*.webp|png` | Responsive images generated by `scripts/optimize-images.sh` |
| `.github/workflows/deploy.yml`, `scripts/compress-uploads.sh` | Publishing to GitHub Pages; compresses any images in `assets/images/uploads/` on the way |
| `sitemap.xml`, `robots.txt`, `llms.txt` | Search engine and AI assistant discovery |
| `redirects/` | Redirects from the old Squarespace URLs |
| `reference/squarespace-export/` | Original saved pages (not deployed) |

## Local preview

```sh
JEKYLL_NO_BUNDLER_REQUIRE=true jekyll serve
# or, with the GitHub Pages gem set:  bundle install && bundle exec jekyll serve
```

## Publishing

Every push to `main` is built and published by `.github/workflows/deploy.yml` (GitHub Actions), usually within two minutes. One-time setup, including the custom domain: [guide 1](docs/1-put-the-site-on-github.md).

## Booking and forms (Google Workspace)

Booking uses Google Calendar appointment schedules, and the inquiry forms use Google Forms, both on the practice's Google Workspace account. Paste the links into `booking.google` and `forms` in `_config.yml`. Until those are set, the Appointments page shows the original Acuity scheduler and forms open the visitor's email app. Step-by-step setup, including the HIPAA BAA and retiring Acuity: [guide 2](docs/2-booking-and-forms.md).

## Images

Add or replace a PNG in `assets/images/original/`, run `scripts/optimize-images.sh` (needs `brew install webp`), and add/update its entry in `_data/images.yml`.
